# Product Inventory Management System (Beginner Java)

## Requirements
- Java JDK installed
- VS Code (optional)

## Run
Open a terminal in this folder and run:

```powershell
javac Main.java
java Main
```

## Collections used
- HashSet: unique product categories
- TreeSet: alphabetical category display
- LinkedHashSet: product names in insertion order
- HashMap<Integer, Integer>: product ID and available quantity
- Additional HashMaps store product names, categories and prices using product IDs.

All information is kept in memory and resets when the program exits.
